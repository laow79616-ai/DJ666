RULES

平台合约规则

这是 DJ666 社区的使用约定，说明你可以做什么、不应做什么，以及平台如何维护秩序。本页是社区规则说明，不是法律意见或律师文书。

欢迎来到 DJ666。注册或继续使用本站，即表示你已阅读并同意遵守以下规则。最新文本以本页为准。

一、关于本站

DJ666 是一个 DJ 音乐随听社区。访客可以浏览公告、收听已发布的音乐，也可以查看公屏记录。注册并登录后，才能参与公屏互动或上传音乐包。用户上传的曲目需经管理员审核后，才会出现在首页列表。

二、注册与账号

  1. 注册时须使用有效的邮箱，并设置妥善保管的密码。邮箱是登录凭证，用户名用于公开展示。
  2. 必须勾选同意本规则后，方可完成注册。所有用户都需遵守本规则，才能注册并参与互动。
  3. 请对本人账号下的行为负责，不要把账号出借给他人。
  4. 用户名应得体、可辨识，不得冒充他人或管理员，不得使用明显违规或骚扰性名称。
  5. 如需修改用户名或登录密码，请到「个人设置」自行更新。

三、行为规范

  1. 请尊重其他用户，保持友善、克制的交流。
  2. 禁止发布违法违规、淫秽色情、暴力恐怖、赌博诈骗、仇恨歧视、骚扰辱骂，或侵犯他人权益的内容。
  3. 禁止垃圾广告、恶意刷屏、发布钓鱼链接，或传播恶意软件。
  4. 禁止试图干扰、破坏网站运行，或未经授权访问他人账号、管理后台及系统数据。

四、音乐与版权

  1. 登录用户可以在「个人设置」中上传音乐包（ZIP / RAR / 7Z 压缩包，内含音频文件），并可自行修改显示名称。用户上传的曲目需经管理员审核通过后，才会出现在首页供所有人播放。管理员也可以直接上传曲目并立即发布。
  2. 上传者应确保对所上传内容拥有相应权利，或已获得合法授权，不得擅自上传侵权作品。
  3. 本站播放功能供社区内收听使用，请勿把平台当作未授权分发渠道。
  4. 如权利人认为内容侵权，可通过站内方式联系管理员处理。

五、公屏聊天

  1. 只有注册并登录的用户可以在公屏发言。
  2. 未登录访客可以浏览公告、听音乐，也可以查看公屏记录，但不能发言或上传。
  3. 发言请简短友善，不要泄露自己或他人的隐私信息。
  4. 管理员可以删除任意一条公屏消息，也可以清空全部公屏。

六、管理与处理

  1. 管理员负责维护社区秩序，可删除违规内容，也可限制或删除违规账号。
  2. 平台可能根据运营需要调整功能、规则或内容展示方式。
  3. 对违反本规则的行为，管理员可依情节采取删除内容、警告或终止账号等措施。我们会尽量合理处置。

七、免责与提示

  1. 用户应对其发布或上传的内容负责。
  2. 因网络、设备或不可抗力导致的暂时中断，平台会尽量恢复，但不保证服务永不中断。
  3. 本规则可能会更新。更新后如你继续使用本站，视为接受更新后的规则。

八、同意

当你在注册时勾选「我已阅读并同意《平台合约规则》」，或在登录后继续使用本站的互动功能，即表示你理解并同意遵守上述约定。

如有疑问，请先阅读本页，或通过站内方式联系管理员。
